# План развития проекта "Мульти--Ассистент"

Этот документ содержит список планируемых улучшений, новых функций и долгосрочных идей для развития бота.

## 🎯 Ближайшие цели (Short-term)

Эти задачи имеют наивысший приоритет и находятся в активной разработке или планируются на ближайшее время.

-   **✔️ Завершить режим "Квиз":**
    -   [ ] Добавить больше тем для викторины.
    -   [ ] Реализовать сохранение рекордов пользователей.
    -   [ ] Ввести систему уровней или достижений.

-   **✔️ Завершить режим "Рекомендации":**
    -   [ ] Улучшить парсинг ответов от LLM для большей стабильности.
    -   [ ] Добавить возможность указывать больше критериев (год выпуска, страна, актеры).
    -   [ ] Сохранять историю рекомендаций, чтобы не предлагать одно и то же.

-   **✔️ Улучшить обработку ошибок:**
    -   [ ] Добавить более информативные сообщения для пользователя, если API OpenAI или Gemini недоступно.
    -   [ ] Внедрить механизм повторных запросов (`retry`) при временных сбоях сети.

## 🚀 Среднесрочные цели (Mid-term)

Функции, которые планируется реализовать после завершения работы над ближайшими целями.

-   **✨ Новый режим: "Генератор изображений":**
    -   Интеграция с моделями для генерации изображений (например, DALL-E 3 или Midjourney).
    -   Пользователь сможет отправлять текстовое описание и получать в ответ картинку.

-   **✨ Персонализация:**
    -   Дать пользователям возможность настраивать "характер" бота в режиме `Chat` (например, более формальный, юмористический, краткий).

-   **✨ Улучшение контекста:**
    -   Перейти от хранения истории чата в оперативной памяти (`MemoryStorage`) к более постоянному хранилищу (например, `Redis` или `SQLite`), чтобы контекст диалога не терялся после перезапуска бота.

-   **✨ Локализация:**
    -   Добавить поддержку нескольких языков интерфейса (английский, испанский и т.д.).

## 🔭 Долгосрочные идеи (Long-term)

Концептуальные идеи, которые могут быть реализованы в далеком будущем.

-   **🧩 Система плагинов:**
    -   Разработать архитектуру, которая позволит легко подключать новые функции в виде плагинов, не затрагивая ядро.

-   **🌐 Веб-интерфейс:**
    -   Создать простой веб-интерфейс для администратора, где можно будет смотреть статистику использования бота, количество активных пользователей и т.д.

-   **🤖 Интеграция с другими сервисами:**
    -   Рассмотреть возможность интеграции с календарем, задачами или новостными лентами.

---
Этот план будет регулярно обновляться в зависимости от отзывов пользователей и появления новых идей.
