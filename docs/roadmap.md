# План развития проекта "Мульти-Ассистент"

Этот документ содержит список планируемых улучшений, новых функций и долгосрочных идей для развития бота, с учетом перехода на персистентное хранилище данных и систему локализации.

## 🎯 Ближайшие цели (Short-term)

Эти задачи имеют наивысший приоритет и являются фундаментом для новых функций.

- **✔️ Внедрение слоя персистентности (База данных):**
    
    - [ ] Спроектировать абстрактный слой (ABC) для репозиториев данных (например, `UserRepository`, `ContextRepository`), чтобы отвязать бизнес-логику от конкретной СУБД.
        
    - [ ] Реализовать первую имплементацию этих репозиториев с использованием `aiosqlite`.
        
    - [ ] Создать таблицы для:
        
        - Пользователей (user_id, выбранный язык, выбранная LLM-модель).
            
        - Истории контекста (для режимов `chat`, `persona` и др.), заменив `context_service.py` на работу с БД.
            
    - [ ] * (Опционально) Изучить и внедрить `aiogram.fsm.storage` на базе `aiosqlite` или `Redis` для хранения состояний FSM.
        
- **✔️ Система локализации (i18n):**
    
    - [ ] Создать сервис для управления языковыми пакетами (например, загрузка текстов из `ru.json`, `en.json`).
        
    - [ ] Добавить в `UserRepository` (из п.1) методы для получения/обновления языка пользователя.
        
    - [ ] Модифицировать все хэндлеры, чтобы тексты интерфейса (кнопки, анонсы) брались из языкового пакета пользователя.
        
    - [ ] Модифицировать "строителей" LLM-запросов (`*_service_build.py`), чтобы они получали язык пользователя и передавали его в системный промпт (для ответов LLM на нужном языке).
        

## 🚀 Среднесрочные цели (Mid-term)

Функции, которые будут реализованы или доработаны _после_ внедрения БД и локализации.

- **✨ Завершить режим "Квиз" (на новой базе):**
    
    - [ ] Реализовать сохранение рекордов пользователей и истории игр в БД.
        
    - [ ] Добавить в БД возможность хранить и управлять темами для викторины.
        
- **✨ Завершить режим "Рекомендации" (на новой базе):**
    
    - [ ] Сохранять историю выданных рекомендаций в БД, чтобы не предлагать одно и то же.
        
    - [ ] Улучшить парсинг ответов от LLM для большей стабильности.
        
- **✨ Новый режим: "Генератор изображений":**
    
    - [ ] Интеграция с моделями для генерации изображений (например, DALL-E или аналоги).
        
    - [ ] Пользователь сможет отправлять текстовое описание и получать в ответ картинку.
        
- **✨ Улучшить обработку ошибок:**
    
    - [ ] Добавить более информативные сообщения для пользователя (на выбранном языке), если API LLM недоступно.
        
    - [ ] Внедрить механизм повторных запросов (`retry`) при временных сбоях сети.
        

## 🔭 Долгосрочные идеи (Long-term)

Концептуальные идеи, которые могут быть реализованы в далеком будущем.

- **✨ Персонализация:**
    
    - Дать пользователям возможность настраивать "характер" бота в режиме `Chat` (например, более формальный, юмористический, краткий) и сохранять это в БД.
        
- **🧩 Система плагинов:**
    
    - Разработать архитектуру, которая позволит легко подключать новые функции в виде плагинов, не затрагивая ядро.
        
- **🌐 Веб-интерфейс:**
    
    - Создать простой веб-интерфейс для администратора (просмотр статистики пользователей из БД).
        
- **🤖 Интеграция с другими сервисами:**
    
    - Рассмотреть возможность интеграции с календарем, задачами или новостными лентами.
